📊 Edición masiva (Excel)

Descargá todos los productos en un Excel, editá lo que quieras (marca, modelo, descripción, categoría y, para MarionShop, el código y el precio) y volvé a subirlo. El código se muestra de forma discreta en Glam y en MarionShop; el precio, solo en MarionShop. No borres la columna "ID" ni agregues filas nuevas. El PDF trae las fotos y casilleros para editar (se ve bien en el celular; abrilo con una app que permita completar formularios). Las fotos no se tocan: para borrar productos o cambiar fotos usá la lista de abajo.
